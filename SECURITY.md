# Security Policy

cibo.hk exposes a public, read-only MCP server and REST API. No API key,
authentication, or write access is required — all tools are read-only queries
over HK IPO public data.

## Reporting a Vulnerability

If you discover a security issue (for example, unintended data exposure or a
write path), please report it via a GitHub issue:

- https://github.com/Gravitational-Beam-Emitter/cibo-api/issues

Please do not disclose sensitive details publicly until they are resolved.
